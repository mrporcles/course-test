# Fonts

The Metropolis `.woff2` files (Regular, Medium, SemiBold) are not committed to this public repo
because their redistribution licence is unconfirmed. Copy them from
`vmware-tanzu-learning/penguin` (`resources/fonts/metropolis/Metropolis-{Regular,Medium,SemiBold}.woff2`,
private repo) into this folder. Without them the renderer falls back to the system sans-serif.
