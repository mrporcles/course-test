## Resources for after the course

A handful of resources are worth bookmarking for ongoing reference:

- **spring.io** — the home of the Spring ecosystem.
- **spring.io/projects/spring-framework** — everything about Spring Core specifically, including the reference documentation, which is genuinely worth reading in full.
- **spring.io/blog** — the official technical blog, where news, releases, and videos are published.
- **Stack Overflow** and **Gitter** — for questions; many Spring projects run a Gitter chat where you can talk directly with the community and with Spring engineers.
- **GitHub** — the Spring Framework is open source, so the source code is public, and GitHub Issues is the place to raise bugs or recommendations for any project in the portfolio.
