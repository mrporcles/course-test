Prerequisites for Spring Framework Essentials:

- Developer experience using a modern Java IDE and build tools such as Maven or Gradle
- Completion of the “Introduction to Spring Professional” course

In this course, you will work through the following modules:

* **Spring Essentials Overview:** Get to know the Spring Framework, its dependency injection container and history, then build familiarity with the Reward Network application.
* **Java Configuration:** Define beans with Java configuration, create an application context, split configuration across files, and understand bean scopes.
* **More on Java Configuration:** Externalize settings with properties, switch behavior with Spring profiles, and use the Spring Expression Language.
* **Annotations and Component Scanning:** Configure beans with annotations, choose between configuration styles, and add startup and shutdown behavior.
* **Inside the Spring Container:** Follow the bean lifecycle through its initialization, use, and destroy phases.
* **Aspect-Oriented Programming:** Apply cross-cutting behavior with pointcut expressions and advice.
* **Testing Spring Applications:** Write unit and integration tests with JUnit 5 and the Spring test framework.
* **JDBC with Spring:** Simplify data access with JdbcTemplate, callbacks, and Spring's exception hierarchy.
* **Transactions:** Manage transactions declaratively, configure propagation and rollback rules, and test transactional code.
